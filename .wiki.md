# Project Summary
DishBar is a modular, scalable, and cloud-ready web application that connects customers with talented home chefs specializing in authentic homemade meals. The platform offers a seamless experience for customers to browse chefs, place orders, and manage meal preferences, while enabling chefs to manage their profiles, menus, and orders effectively. DishBar positions itself as a community-focused marketplace for homemade meals, inviting both customers and chefs to engage through its tagline: "Homemade Meals From Trusted Home Chefs Near You."

# Project Module Description
The project consists of three main portals:
1. **Customer Portal**: Enables customers to register, log in, browse chefs, place orders, manage favorites, track orders, and access notifications.
2. **Chef Portal**: Allows chefs to manage their profiles, upload menus, handle orders, and interact with customers.
3. **Admin Portal**: Facilitates administrative functions for managing users, chefs, orders, and analytics, including chef approval workflows and notifications.

# Usage
To get started with the project, follow these steps:
1. **Install Dependencies**:
   - Navigate to the `app/backend` directory and install Python dependencies using `pip install -r requirements.txt`.
   - Navigate to the `app/frontend` directory and install JavaScript dependencies with `pnpm install`.

2. **Build the Frontend**:
   - Run the command `pnpm run build` in the `app/frontend` directory to build the frontend application.

3. **Run the Backend**:
   - Start the FastAPI server by executing `uvicorn main:app --reload` in the `app/backend` directory.

4. **Access the Application**:
   - Use the provided URLs to access the customer, chef, and admin portals.
